# CIFAR-100 ACD models — seed 3201, final epoch 240

Seven ACD student checkpoints and five distinct pretrained teachers, exported from the completed CIFAR-100 reruns. This release supplies portable evaluation weights, the seven matching configs, official fine-label class order, a model guide, provenance manifest and SHA256 checksums. Model weights total approximately 170 MB; download only the pair you need.

**Read `MODEL_GUIDE.md` for model selection, normalization, evaluation, teacher use, checkpoint format and provenance.** `model_manifest.json` maps filenames to architectures and records both the original and exported hashes. `verification.json` reports fresh evaluation of all twelve models on the complete official 10,000-image test split.

All students use seed 3201, final epoch 240, cosine head scale 30 and **ETF off**. Every student Top-1 matches its archived record. These are single-run reconstruction results, separate from the paper's historical aggregate results. No ImageNet model or detector is included.

## Quick evaluation

After installing this repository, download these two assets into `checkpoints/`:

- `acd_res56_res20_s3201_e240.pth`
- `res56_res20.json`

```bash
python train.py --config checkpoints/res56_res20.json \
  --data-root data --download \
  --evaluate checkpoints/acd_res56_res20_s3201_e240.pth \
  --device cpu --workers 0
```

The release tag targets the existing source commit `cd7bc8a964991de677eb664756da35f2eaccbc4a`. The command above was checked against that unmodified source and returns 71.08% on 10,000 images. Additional repository utilities are not required to use these weights.

To train a new student, also download `teacher_resnet56_cifar100.pth` and use it with `--teacher-checkpoint`. See the model guide for the full command and other pairs.

## Contents and integrity

- 7 `acd_<pair>_s3201_e240.pth` student weights.
- 5 `teacher_<architecture>_cifar100.pth` affine teacher weights.
- 7 matching pair configurations (`<pair>.json`).
- `cifar100_classes.json`, `MODEL_GUIDE.md`, `model_manifest.json`, `verification.json`, `SHA256SUMS`.

The `.pth` assets contain model tensors and basic metadata and load with `torch.load(..., weights_only=True)`. They omit optimizer and scheduler state and **cannot be used for training resume**. Use the current trainer's `latest.pth` for that purpose. Exported file hashes differ from the original training archives; the manifest records both.

For all assets downloaded into one directory, run `sha256sum -c SHA256SUMS`. For a selected subset, run `sha256sum --ignore-missing -c SHA256SUMS` and verify that each downloaded file is checked.
