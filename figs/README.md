# Figures and plot data

All figures have PNG previews plus SVG and PDF versions for reuse. Files are relative to the repository root.

| Asset | Purpose and source |
|---|---|
| `method.*` | ACI/SICD overview copied from `laniusnan/KD/paper_assets/acd_figures/diagram_drafts_20261116/v4_horizontal/figures/method_horizontal.*`; shows optional ETF, which is off in released reruns |
| `workflow.*` | Download → train → evaluate → export workflow, drawn by `tools/make_figures.py` |
| `cifar100_results.*` | Final single-seed Top-1 values from `results/cifar100_rerun.json`; no implied comparison with a KD baseline or historical manuscript means |
| `training_curves.*` | Unsmooth training loss and training Top-1 from `results/training_curves.json`; seven 240-epoch seed3201 runs |

Regenerate workflow and numerical plots:

```bash
pip install -e '.[figures]'
python -m tools.make_figures
```

The method artwork is an imported vector asset and is not regenerated by this command. Its exact source and hashes are in `figs/provenance.json`.

Plot a user's completed-epoch log:

```bash
python -m tools.plot_history --history outputs/my_run/history.jsonl --output outputs/my_run/curves
```

This produces training-loss and evaluation-accuracy panels. The archived training curves in this folder use **training** accuracy on 100,000 augmented views per epoch. They contain no intermediate test curves; complete test evaluation was recorded at the final epoch. Different pairs use different CE/KD weights, so objective values are not directly comparable between all pairs.
